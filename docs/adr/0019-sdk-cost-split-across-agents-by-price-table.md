# Custo do SDK dividido entre os agentes pela tabela de preços

O ADR-0014 manda usar o custo que o SDK informar e conferi-lo contra a tabela pública. O SDK informa custo por modelo e por turno (`model_usage` no `ResultMessage`), mas o Rastro registra uso por agente, e dois agentes podem usar o mesmo modelo. Então, a cada turno, os tokens são somados por agente e modelo a partir das respostas do modelo (o `usage` de cada `AssistantMessage`, contado uma vez por `message_id`, atribuído pelo `parent_tool_use_id` ao especialista da delegação), e o custo do SDK de cada modelo é dividido entre os agentes na proporção do custo que a tabela dá a cada um. O evento `usage` grava os dois valores, `cost_usd` (o usado) e `price_table_cost_usd` (a conferência), e a CLI mostra os dois lado a lado. Quando o SDK não informa custo, ou informa zero, `cost_usd` é o da tabela.

Se o SDK contar um modelo que não apareceu em nenhuma resposta, os tokens dele vão para o especialista do turno, se houve um só, ou para a Recepção. Os campos novos do evento `usage` (tokens lidos e gravados no cache e `price_table_cost_usd`) só acrescentam chaves, então a versão do esquema do Rastro (ADR-0010) continua 1.
